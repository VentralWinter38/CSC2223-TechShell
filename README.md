## Overview

TechShell is a Unix-like command shell written in C.  
It mimics the Bash shell by prompting the user for input, parsing the command, and executing it in a child process.

The shell supports:

- Execution of system commands using `fork()` and `execvp()`
- Built-in commands (`cd`, `exit`, `quit`)
- Input redirection using `<`
- Output redirection using `>`
- Combined redirection (`command < in.txt > out.txt`)
- Prompt display showing:
  - `~$` when in the user's home directory
  - The current directory name otherwise (e.g., `Desktop$`)

Errors generated by the shell itself follow this format:

```
Error N (Error Message)
```

where `N` is the system error number and the message comes from `strerror(errno)`.

This program does **not** use `system()` or `popen()` and relies strictly on low-level UNIX process control functions.

## How to Clone, Compile, and Run

### 1. Clone the Repository

```bash
git clone https://github.com/VentralWinter38/CSC2223-TechShell
cd TechShell
```


---

### 2. Compile the Program

```bash
gcc -Wall -Wextra -std=c11 techshell.c -o techshell
```

Explanation of flags:

- `-Wall` enables common compiler warnings  
- `-Wextra` enables additional warnings  
- `-std=c11` compiles using the C11 standard  

---

### 3. Run the Program

```bash
./techshell
```

To exit the shell:

```bash
exit
```

or

```bash
quit
```

## Implemented Features

### Built-in Commands
- `cd [directory]`
- `exit`
- `quit`

Test example:

```bash
cd ..
pwd
```

---

### External Commands
Any executable available in the system `PATH` can be run.

Test examples:

```bash
ls
ps
whereis ps
/bin/ps u
```

---

### Input Redirection

```bash
wc -l < file.txt
```

---

### Output Redirection

```bash
ps u > output.txt
```

---

### Combined Redirection

```bash
wc -l < input.txt > output.txt
```

---

### Quoted Arguments

```bash
echo "hello world"
echo 'hello world'
```

---

### Escaped Spaces

```bash
echo hello\ world
```

---

## Known Limitations / Not Implemented

The following common shell features are **not implemented**:

- Pipes (`|`)
- Append redirection (`>>`)
- Background execution (`&`)
- Environment variable expansion (`$VAR`)
- Command history
- Tab completion
- Custom signal handling

---

## Error Handling

TechShell properly handles:

- Invalid commands  
- Permission errors  
- Missing redirection files  
- `cd` to invalid directories  

Example:

```bash
horseface
Error 2 (No such file or directory)

cd /root
Error 13 (Permission denied)
```

## How to Test Core Functionality

After compiling and running:

```bash
./techshell
```

Run this sequence:

```bash
pwd
cd ..
pwd
ls
ps u > ps.out
wc -l < ps.out
wc -l < ps.out > wc.out
cat wc.out
rm ps.out wc.out
exit
```

If all of these work correctly, the required functionality is implemented properly. The easiest sign if any of them haven't worked correctly would be an error statement after entering the command.
